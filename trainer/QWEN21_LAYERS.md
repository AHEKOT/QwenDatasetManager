# Qwen Image 2.1: совместная генерация слоёв

В форме обучения выберите **Layered image training → Qwen Image 2.1 — Joint PSD layers LoRA**.
Ключ пресета: `qwen_layered_lora`; архитектура: `qwen_image_2_layered`.
Это экспериментальная адаптация QI2, которую нужно обучать на многослойных данных.
Само наличие пресета не означает, что исходный checkpoint уже умеет правильно разделять сцену.

## Датасет

```text
Datasets/MyLayers/
  img/
    scene-a.psd
    scene-a.txt
    scene-b.psd
    scene-b.txt
  Control1/
    scene-a.png
```

`scene-a` обучает получение стека из плоского Control1 и инструкции.
`scene-b` обучает создание стека с нуля по подписи. Отсутствующий Control1 — отсутствие
визуального conditioning, без подстановки чёрной картинки. Можно смешивать оба вида примеров.
Control1 поддерживает PNG/JPG/JPEG/WebP; имена без расширения должны однозначно соответствовать
PSD. Control2/3 в этом формате запрещены. Изображения PNG рядом с PSD не являются targets.
PSD лежат непосредственно в `img/`, без вложенных каталогов. Подписи описывают сцену или
операцию; названия слоёв не являются текстовой разметкой для модели.

**Layer slots** задаёт одинаковое число слоёв для всего задания: 1–20, по умолчанию 4.
Меньшее фактическое число дополняется полностью прозрачными верхними слоями. При превышении
лимита файл отклоняется, слои не объединяются и не отбрасываются. Для обучения полезно
согласовать смысл и порядок слоёв между документами, например фон → предмет → передний план.
Число слотов нужно сохранить для дальнейшего инференса этого адаптера.

## Семантика PSD

Поддерживается PSD, RGB, 8 бит на канал. Разбор выполняет `psd-tools[composite]==1.22.0`
из зависимостей **trainer**, не основного веб-приложения. Зависимость добавлена в requirements
и установлена в `trainer/.venv` вместе с `aggdraw` и `attrs`.

- Видимые слои читаются **снизу вверх**, как их перечисляет psd-tools; порядок не переворачивается.
- Каждый слой рендерится на полном холсте документа, со смещением, собственной альфой,
  opacity, fill opacity и масками. RGB полностью прозрачных пикселей обнуляется.
- Обычные группы Normal/Pass Through с opacity/fill 100%, без масок и эффектов раскрываются
  с сохранением порядка дочерних слоёв. Скрытые слои и скрытые группы исключаются.
- Поддерживаются пиксельные слои, текст и smart objects с сохранёнными растровыми пикселями.
  Текст и smart objects в target становятся RGBA-растром.
- Live effects, clipping, Blend If, adjustment/shape layers, нестандартные blend modes,
  artboards и группы с общей маской/opacity отклоняются с именем проблемного слоя.
  Такие особенности нужно заранее растрировать в нужные Normal RGBA-слои.
- Повреждённые PSD и Control1 не заменяются другим примером молча.

Не обещается воспроизведение произвольных функций Photoshop. Этот формат описывает стек
обычных RGBA-холстов с операцией alpha-over. Иерархия групп и исходные имена не генерируются.

## Обучение и инференс

```text
PSD → L × RGBA(H,W) → VAE каждого слоя → L × latent(64,h,w)
                                           ↓
текст + необязательный Control1 → один DiT со всеми шумными слоями
                                           ↓
                        совместный flow-matching / denoising
                                           ↓
                   VAE каждого слоя → RGBA-стек → PSD + PNG
```

Все target-слои получают один timestep документа. У них общий двунаправленный attention:
нижний слой может учитывать верхний и наоборот. Текст и Control1 остаются чистым причинным
префиксом. Пространственные координаты RoPE повторяются для каждого слоя; первая ось задаёт
его порядковый номер относительно префикса. Меняются target-mask, timestep modulation,
граница KV-префикса и attention metadata. Обычный QI2 сохраняет прежний режим одного target.

Внутри общего trainer буфера используется форма `B,C,L*h,w`; это только способ хранения.
VAE получает отдельные холсты, а DiT — одну последовательность с L отдельными сетками.
Слои не являются независимыми элементами batch и не являются высоким изображением для VAE.
Потеря — MSE flow velocity `noise - clean_latents` по всем слоям, включая пустые верхние слоты.
Нативный RGBA VAE заморожен: его дообучение для этого представления не требуется.

Один процесс генерации содержит обычные шаги денойзинга; «совместно» не означает один
diffusion step. На каждом шаге все слои предсказываются вместе. CFG, если включён,
добавляет обычное unconditional-предсказание для того же полного стека.

Batch size — 1 документ, gradient accumulation доступен. Это исключает смешивание разных
структур visual conditioning внутри одного batch. Resize/crop одинаковы для всех слоёв;
Control1 используется как исходный визуальный reference по правилам QI2. Flips,
regularization, альтернативные losses, DOP/BPP, guidance losses, старый RGBA validation
и advanced process override в этом пресете отключены. Разрешены LoRA/LoKr и штатные
параметры оптимизатора, квантизации, offloading и кэширования.

Латентный кэш учитывает версию формата, число слотов, SHA-256 PSD и геометрию crop.
Кэш visual text embeddings учитывает содержимое Control1. Рост числа слотов увеличивает
число токенов DiT и потребление памяти; максимальное значение не является гарантией
вместимости на конкретной GPU.

Сэмплы сохраняются как composite `.png` и многослойный `.psd`, снизу вверх, с именами
`Layer 01`, `Layer 02`, … . В просмотрщике доступна кнопка **Download PSD**; ZIP сэмплов
включает PSD. Удаление PNG-сэмпла удаляет соответствующий PSD.
Для внешнего инференса нужен этот layered pipeline и совпадающий `layer_slots`:
обычный одноизображенческий QI2 pipeline не воспроизводит новое attention-представление.

Для ComfyUI добавлен отдельный пак [ComfyUI-QDM-QI2-Layers](../ComfyUI-QDM-QI2-Layers/README.md).
В нём есть готовые workflow на 4 и 20 слотов, загрузчик адаптера, совместный sampler,
декодирование RGBA и экспорт PSD/PNG. Пак использует нативную QI2 из ComfyUI и повторяет
контракт тренера; зависимости trainer для его работы не нужны.

## Проверка

Добавлены `tests/test_trainer_layers.py` (контракт сервиса) и
`trainer/test_qwen21_layers.py` (PSD round trip, порядок/alpha/offset, общий crop,
независимые VAE-холсты, общая target-маска и градиент между слоями маленького DiT).
Эти тесты тренера пока не запускались. При подготовке PrismLayersPro проверены
чтение каждого созданного PSD, порядок слоёв, альфа, Control1 и подписи.
CPU-проверки нового ComfyUI-пака сверяют RoPE с классом тренера, schedule с Diffusers,
общую target-маску, PSD round trip и связи workflow.
Качество обучения и работоспособность полного GPU-тракта пока не подтверждены запуском.

API парсера: [psd-tools](https://psd-tools.readthedocs.io/en/latest/reference/psd_tools.html),
[Layer API](https://psd-tools.readthedocs.io/en/latest/reference/psd_tools.api.layers.html).
