Randomizes basenames across the current dataset while keeping every related image and caption in sync.

Compress

Runs PNG optimization over the dataset and keeps the folder structure unchanged.

Effect Smaller PNG files

Compression targets storage size while preserving PNG format.

Output Storage report

Effect Matched control canvases

Black bars are added where needed when aspect ratios differ.

Use Case Training consistency

Helpful when external pipelines produced controls with inconsistent dimensions.
